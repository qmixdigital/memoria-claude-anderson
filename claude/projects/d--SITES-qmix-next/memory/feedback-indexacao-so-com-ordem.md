Indexação paga (Apex, Rapid URL Indexer) só sai quando o Anderson solicitar, caso a caso. Vale também ao marcar entrega como publicada por script: não chamar `enviarParaIndexacao` por conta própria, mesmo que o botão da tela faça isso.

**Why:** em 01/10/2026 lancei o link do DM do Perfume Árabe no pedido 129 e mandei para o Apex "como o botão faz"; ele respondeu "Indexação só pode enviar quando eu solicitar. Esse link já está indexado". Cada URL custa crédito, e portal forte (DM) indexa sozinho.

**How to apply:** ao gravar URL publicada (entrega, matéria, guest post), parar antes da indexação e perguntar no resumo. Antes de enviar, vale conferir se a URL já está indexada. Ver também [[qmix-publicacao-automatica]].
