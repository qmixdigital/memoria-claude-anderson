Sempre que eu criar, publicar ou alterar uma página/ferramenta/URL, fornecer a URL como **link clicável** (markdown `[url](url)`), não como texto puro.

**Why:** o usuário quer poder abrir direto do terminal sem copiar e colar.

**How to apply:** ao terminar qualquer deploy que gere ou mexa numa URL pública (ferramentas, artigos, landing pages, redirects), listar a(s) URL(s) finais em markdown clicável no resumo. Vale para o subdomínio [[ferramentas-subdominio]] e para qmix.com.br.
