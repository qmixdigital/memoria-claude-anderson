pendente ficou presa neles. Para reativar: `update produtos set status='ativo' where contato='Lucas Martinatto'`.

"Lucas" no banco, **Lucas Pelisari**, dono dos blogs parceiros gratuitos (lista lucas.txt, custo 0): esses continuam ativos.
