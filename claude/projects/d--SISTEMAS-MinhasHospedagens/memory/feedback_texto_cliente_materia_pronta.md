O Anderson aprovou ("Ficou excelente!") o texto abaixo para mandar ao cliente quando as matérias
do painel ficam prontas. Quando ele pedir "envia a observação de link interno", é o último
parágrafo, sem precisar reescrever.

**Why:** ele repassa a mensagem direto ao cliente; texto curto, uma linha por dado, sem ensaio.

**How to apply:** por matéria: número + portal em negrito, Título, Link do conteudo.qmix, Âncora
"x" → URL do cliente. Depois "Aguardo sua autorização para encaminhar aos portais." e, quando
houver link interno, o parágrafo fixo:

> Uma observação: no fim de cada matéria inserimos um link interno para outro post nosso já
> publicado no mesmo portal. Isso deixa o conteúdo mais natural aos olhos do editor e do Google e,
> no futuro, o seu artigo também vai receber link interno das próximas publicações, sem ficar
> órfão dentro do site.

Abertura: "Seguem os dois conteúdos prontos para sua análise e aprovação:". Para orçamento, o
modelo "Segue os valores" com portal, praça/DA/tráfego, valor e promo, total e o que está incluso
(matéria 1.200+ palavras, link dofollow, imagem, permanente, indexada, sem marcação de patrocinado).
