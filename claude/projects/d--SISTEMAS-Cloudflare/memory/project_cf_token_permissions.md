Token personalizado "Redirect Rules Manager" requer estas permissões:

1. Conta > Conjuntos de regras da conta > Editar
2. Zona > Zona > Lido
3. Zona > Redirecionamento único > Editar

Nota: "Zone Rulesets" não existe no dropdown em português. O nome correto para Single Redirects é "Redirecionamento único" (encontrado no dropdown de permissões de Zona).

Recursos de zona: Incluir > Todas as zonas de uma conta > Anderson Alves
