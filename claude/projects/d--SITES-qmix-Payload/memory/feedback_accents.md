Always use proper Portuguese accents (acentuação) in all content written in Portuguese. Missing accents is a serious error.

**Why:** The user flagged this as "um erro muito grande" - Portuguese text without accents looks unprofessional and incorrect.

**How to apply:** When writing any Portuguese text (product descriptions, article content, etc.), always include proper accents: á, é, í, ó, ú, â, ê, ô, ã, õ, ç, etc.
