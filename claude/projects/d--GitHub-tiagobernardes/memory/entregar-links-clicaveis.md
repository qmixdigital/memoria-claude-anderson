Ao criar ou publicar páginas, **sempre terminar a resposta com a lista das
URLs completas e clicáveis** das páginas novas, sem esperar que ele peça.

**Why:** ele pediu isso duas vezes seguidas. Ele quer conferir o resultado no
navegador imediatamente, e ficar caçando o endereço no meio do relatório ou
montando a URL na mão custa tempo dele.

**How to apply:** URL completa com `https://`, uma por linha ou em tabela, com
um rótulo curto do que é cada página. Verificar o código HTTP antes de entregar
— nunca passar link que redireciona ou dá erro. Vale também para páginas
alteradas de forma relevante, não só as novas.
