---
name: Trabalho autônomo
description: Usuário quer trabalho 100% autônomo sem pedir autorizações para comandos ou edições
type: feedback
---

Trabalhar de forma completamente autônoma. Não pedir autorizações para nenhuma ação (build, edição, delete, etc).

**Why:** O usuário tem outras coisas para fazer e não quer ficar aprovando cada ação.
**How to apply:** Executar tudo diretamente sem solicitar confirmação. Isso se aplica a comandos bash, edições de arquivo, builds, deploys e qualquer outra ação.
