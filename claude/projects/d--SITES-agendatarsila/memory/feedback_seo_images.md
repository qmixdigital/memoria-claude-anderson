All content pages must have hero images with keyword-rich alt text.

**Why:** User values visual SEO — images in hero, OG tags, and Article schema improve CTR and indexing.

**How to apply:** When creating new pages, always generate a 1216x640 WEBP image via Runware API and place it in 3 locations: hero `<img>` with keyword alt, OG `images` meta, and Article schema `image` field.
