---
name: No emojis in professional sites
description: User strongly dislikes emojis as icons/decorative elements - always use SVG icons instead
type: feedback
---

NUNCA usar emojis como ícones ou elementos decorativos em sites. Emojis são "de amadores, pessoas que não aprenderam até hoje a fazer um site".

**Why:** O utilizador considera emojis extremamente não-profissionais. Qualquer ícone deve ser SVG personalizado.

**How to apply:** Em TODOS os projetos, criar ícones SVG como componentes React (ou inline SVG em HTML estático). Aplicar cor via props/CSS. Nunca substituir por emojis mesmo como placeholder.
