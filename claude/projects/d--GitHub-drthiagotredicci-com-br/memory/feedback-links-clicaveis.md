Sempre fornecer links clicáveis, com a URL completa (https://...), ao citar páginas, posts ou URLs em relatórios e resumos. Nunca listar só o caminho ("/doutor") ou o slug.

**Why:** Pedido explícito em 10/09/2026, no projeto drthiagotredicci.com.br, depois de um relatório que listava páginas só pelo caminho. Ele abre as páginas direto do relatório para analisar o que fazer.

**How to apply:** Em tabelas e listas, usar a URL inteira como texto do link ou o nome da página linkado para a URL completa. Vale para site, blog e páginas de terceiros (Doctoralia, Google). Quando o relatório for para copiar e colar, a URL completa deve aparecer como texto, não só escondida atrás de um rótulo.
