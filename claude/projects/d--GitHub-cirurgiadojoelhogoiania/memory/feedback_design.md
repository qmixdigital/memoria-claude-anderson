User rejected 3 rounds of simplified wireframe-style mockups for a medical site redesign. What worked was a full production-grade HTML/CSS page with:
- Premium editorial typography (Playfair Display + DM Sans)
- Rich color depth (deep blue #002B45 + gold #E8AD0C)
- Glassmorphism, floating cards, subtle animations
- Complete page layout (not fragments)

**Why:** User has high visual standards and found wireframe-style options looked worse than the existing site. Generic AI aesthetics (teal, green, minimalist) were all rejected.

**How to apply:** Always present full, production-quality mockups. Use the frontend-design skill. Never propose simplified wireframes or generic color schemes. The user values design quality over speed of iteration.
