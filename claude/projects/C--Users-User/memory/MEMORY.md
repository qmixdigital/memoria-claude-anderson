# User Preferences

## Design & UI
- **No scroll animations**: User dislikes entrance animations (fade-in, slide-left/right, stagger, scale on scroll). Only hover effects are acceptable.
- **Minimal animations**: Keep animations to mouse hover interactions only. No cards moving around.
- **No forms**: User prefers CTA buttons (WhatsApp, phone) over contact forms. "People don't like filling out forms anymore."
