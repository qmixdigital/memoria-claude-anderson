# Nome do cliente: segmento

Memória do cliente para matérias em portais de terceiros. Criada em DD/MM/AAAA a partir do
primeiro briefing. **Atualizar aqui** a cada matéria: âncora, URL, portal, tema, link da entrega.

- **Site:** dominio.com.br (e páginas de destino usadas)
- **Segmento:** área de atuação
- **Localização:** cidade, UF (se for negócio local)
- **Credenciais verificadas:** CRM/RQE, formação, tempo de atuação, fonte de cada dado
- **Regras editoriais específicas:** o que o cliente exige ou proíbe (ordem em listas, concorrentes, CTA, tom)
- **Fatos e dados úteis recorrentes:** números com fonte e ano, para reaproveitar sem repetir texto
- **Ângulos ainda não usados:** ideias guardadas para as próximas matérias
