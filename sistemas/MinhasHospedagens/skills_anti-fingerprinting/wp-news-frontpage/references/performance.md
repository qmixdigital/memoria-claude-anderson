# Performance Budget

News portals live or die by Core Web Vitals. Slow portals lose AdSense revenue (lower viewability), lose backlink credibility (Google deindexes thin slow sites first), and lose direct traffic. Every front-page generated by this skill must hit these targets.

## Targets

| Metric | Target | Hard ceiling |
|---|---|---|
| LCP | under 2.0s | 2.5s |
| CLS | under 0.05 | 0.1 |
| INP | under 150ms | 200ms |
| Total JS on front-page | under 100KB | 200KB |
| Total CSS on front-page | under 60KB | 100KB |
| Largest image (hero) | under 120KB | 200KB |

Test with PageSpeed Insights on mobile, not desktop. Brazilian portal traffic is 70%+ mobile.

## LCP optimization rules

The Largest Contentful Paint element is almost always the hero image. Rules:

1. **Set explicit width and height** on the hero `<img>` to prevent CLS reflow.
2. **Use `fetchpriority="high"`** on the hero image. This is a 2024+ browser feature with strong support.
3. **Use `loading="eager"`** on hero, never `loading="lazy"`. Lazy on the LCP element kills LCP.
4. **Preload the hero image** in `<head>` if the URL is known at template-render time:
   ```php
   add_action( 'wp_head', function() {
       if ( is_front_page() ) {
           $hero = get_posts( array( 'numberposts' => 1, 'category_name' => 'destaque' ) );
           if ( $hero ) {
               $img = get_the_post_thumbnail_url( $hero[0]->ID, 'large' );
               echo '<link rel="preload" as="image" href="' . esc_url( $img ) . '" fetchpriority="high">';
           }
       }
   }, 1 );
   ```
5. **Serve WebP or AVIF** with proper MIME types. Use the WordPress 6.5+ native AVIF support if available, otherwise use a plugin like ShortPixel or convert at upload time.
6. **Use responsive `srcset`** for the hero so mobile gets a smaller image:
   ```html
   <img src="hero-1200.webp"
        srcset="hero-600.webp 600w, hero-900.webp 900w, hero-1200.webp 1200w"
        sizes="(max-width: 768px) 100vw, 1200px"
        width="1200" height="675"
        fetchpriority="high"
        loading="eager"
        alt="...">
   ```

## CLS optimization rules

1. **Every image needs explicit width and height attributes.** No exceptions. Aspect ratio CSS is a backup, not a replacement.
2. **Reserve space for AdSense slots.** Set min-height on ad containers matching the expected ad size:
   ```css
   .ad-leaderboard { min-height: 90px; }
   .ad-medium-rectangle { min-height: 250px; }
   .ad-half-page { min-height: 600px; }
   ```
3. **Self-host fonts** with `font-display: swap` plus a preload. Avoid Google Fonts CDN late-binding.
4. **Avoid late-injecting elements** above the fold via JavaScript. Newsletters popups, cookie banners, sticky headers must render with reserved space or appear below the fold.

## INP optimization rules

INP (Interaction to Next Paint) replaced FID in 2024. It measures responsiveness throughout the session, not just first input.

1. **Defer non-critical JS.** Only the breaking news ticker (if present) needs immediate JS. Everything else loads with `defer` or is loaded after `DOMContentLoaded`.
2. **Avoid heavy event handlers on scroll.** If a sticky element needs scroll listening, use `passive: true` and `requestAnimationFrame`.
3. **Lazy-load below-fold images** with `loading="lazy"` (browser-native, no JS library needed).
4. **Avoid jQuery if possible.** Many WordPress plugins still pull jQuery. Use `wp_dequeue_script( 'jquery' )` if the front-page does not need it.

## CSS strategy

Two acceptable patterns. Pick one per portal.

**Pattern A: Inline critical CSS, defer the rest.**

```php
add_action( 'wp_head', function() {
    if ( is_front_page() ) {
        echo '<style>' . file_get_contents( get_stylesheet_directory() . '/assets/critical-home.css' ) . '</style>';
        echo '<link rel="preload" href="' . get_stylesheet_directory_uri() . '/assets/home.css" as="style" onload="this.rel=\'stylesheet\'">';
        echo '<noscript><link rel="stylesheet" href="' . get_stylesheet_directory_uri() . '/assets/home.css"></noscript>';
    }
}, 5 );
```

**Pattern B: Single small enqueued stylesheet.**

If total home CSS fits in 30KB, just enqueue it normally. Simpler, fewer moving parts.

## Font strategy

Pick one strategy per portal. Vary across the network.

| Strategy | Pros | Cons |
|---|---|---|
| System fonts only (no @font-face) | Zero font load, fastest | Less brand identity |
| Self-hosted single weight | Fast, branded | Limited typographic range |
| Self-hosted variable font | Full weight range, one file | Larger initial download |
| Google Fonts (preconnected) | Easy, popular | Third-party DNS, GDPR risk |

For Brazilian Portuguese, ensure the chosen font supports Latin Extended-A (covers ç, á, é, etc.).

## Image plugins worth using

- **ShortPixel** or **Imagify** for automatic WebP/AVIF conversion.
- **Optimole** if budget allows, CDN-based.
- **Self-hosted alternative:** WP-CLI with `wp media regenerate` plus a local cwebp pipeline.

Avoid heavy "all-in-one" image plugins that also do lazy loading via JS. Browser-native lazy is sufficient.

## What to avoid on every front-page

- **Sliders that auto-rotate.** They tank LCP and add CLS. If hero must be a slider, make it a static-on-load slider with rotation only after user interaction.
- **Embedded YouTube videos above the fold.** Lazy-load with a thumbnail click-to-play pattern.
- **Massive sprite icons.** Use inline SVG for individual icons instead of an icon font or sprite sheet.
- **Cookie consent banners that block content.** GDPR/LGPD compliance is necessary, but use a non-blocking implementation that does not delay LCP.
- **Heavy ad networks above AdSense.** If the portal runs additional ad networks, place them below the fold only.

## Validation checklist before shipping

Before considering the front-page done, run:

1. PageSpeed Insights mobile, ensure all 4 vitals are green.
2. View source, count `<script>` tags, ensure under 8.
3. Network tab, check total transfer for first load, target under 800KB.
4. Throttle to "Slow 3G" in DevTools, verify the page is usable within 5 seconds.
5. Check `<head>` for the preload hint on the hero image.
