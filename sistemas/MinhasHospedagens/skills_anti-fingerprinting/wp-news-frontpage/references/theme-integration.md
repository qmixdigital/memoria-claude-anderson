# Theme Integration

How to make `front-page.php` work correctly with each parent theme. Each theme has its own way of disabling the default homepage and exposing hooks.

## GeneratePress

GeneratePress is the leanest of the three modern themes. The child theme `front-page.php` takes over completely.

**Disabling default sidebar layout per template:**

```php
add_filter( 'generate_sidebar_layout', function() {
    return 'no-sidebar'; // or 'left-sidebar', 'right-sidebar', 'both-sidebars'
});
```

**Disabling default content padding for full-bleed hero:**

```php
add_filter( 'generate_blog_columns', '__return_false' );
add_action( 'wp_enqueue_scripts', function() {
    wp_add_inline_style( 'generate-style', '
        body.home .site-content { padding: 0; }
        body.home .inside-article { padding: 0; }
    ');
});
```

**Container width override:**

GeneratePress respects the Customizer container width. For a full-bleed front-page, wrap content in a `.gp-full-bleed` div with `max-width: 100vw; margin-left: calc(50% - 50vw);`.

**Hooks worth knowing:**
- `generate_before_main_content`: fires before the main content area
- `generate_after_main_content`: fires after
- `generate_before_header` and `generate_after_header`: for breaking news strips
- `generate_inside_navigation`: to inject category tabs into the menu

**Disabling the Customizer's homepage settings interference:**

```php
remove_action( 'generate_before_main_content', 'generate_construct_header' );
```

Use sparingly. GeneratePress is built to be lean, so most of its defaults are fine.

## Blocksy

Blocksy is more opinionated than GP. It has a homepage builder concept ("Hero Sections") that competes with `front-page.php`.

**Forcing the custom template to win:**

In the Blocksy Customizer, go to Page Settings and set "Page Structure" to "Default" with no hero. Then in `front-page.php`, suppress Blocksy's default hooks:

```php
add_action( 'wp', function() {
    if ( is_front_page() ) {
        remove_all_actions( 'blocksy:hero:before' );
        remove_all_actions( 'blocksy:hero:after' );
    }
});
```

**Disabling the default content wrapper:**

```php
add_filter( 'blocksy:single:has-content-wrapper', '__return_false' );
```

**Hooks worth knowing:**
- `blocksy:single:before` and `blocksy:single:after`
- `blocksy:header:after`: for breaking news strips
- `blocksy:archive:hero`: Blocksy's archive hero, replace with custom

**Color scheme integration:**

Blocksy uses CSS variables like `--theme-palette-color-1` through `--theme-palette-color-8`. Use these in custom CSS instead of hardcoded colors so the portal respects Customizer settings.

```css
.news-card__title { color: var(--theme-palette-color-1); }
.news-card__category { color: var(--theme-palette-color-3); }
```

## Kadence

Kadence is design-system-focused with strong template editing. Like Blocksy, it has its own hero builder.

**Disabling the default hero on home:**

```php
add_filter( 'kadence_show_hero_section', function( $show ) {
    if ( is_front_page() ) {
        return false;
    }
    return $show;
});
```

**Disabling the default page title:**

```php
add_filter( 'kadence_post_title', function( $show ) {
    if ( is_front_page() ) {
        return false;
    }
    return $show;
});
```

**Container layout per template:**

```php
add_filter( 'kadence_blog_layout', function() { return 'fullwidth'; });
add_filter( 'kadence_blog_columns', function() { return 'three'; });
```

**Hooks worth knowing:**
- `kadence_before_wrapper`
- `kadence_after_wrapper`
- `kadence_hero_section`: to inject custom hero

**CSS variables:**

Kadence exposes `--global-palette1` through `--global-palette9`, plus typography vars like `--global-heading-font-family`. Use these.

## SmartMag (legacy)

SmartMag is being phased out across the network. New portals should not use it. For existing SmartMag portals, the approach is different: SmartMag includes its own homepage builder via Bunyad framework.

**For SmartMag portals being kept:**

The cleanest path is to bypass SmartMag's homepage builder entirely:

```php
// In front-page.php
remove_action( 'bunyad_loop_main', 'bunyad_loop_main' );
remove_all_actions( 'bunyad_homepage' );
```

Then build the homepage in raw PHP using `WP_Query`. This makes the SmartMag portal structurally indistinguishable from a non-SmartMag portal at the front-page level, which helps fingerprint reduction during the migration period.

**For migrating SmartMag to GP/Blocksy/Kadence:**

1. Export current content (posts, terms, media), leaving it intact.
2. Switch parent theme to the new one.
3. Drop in the front-page.php generated by this skill.
4. Reconfigure menus and widgets in the new theme.
5. Test mobile rendering aggressively. SmartMag has heavy CSS that does not transfer.

## Common patterns across all themes

### Enqueueing front-page-specific styles

Always conditional, never global:

```php
add_action( 'wp_enqueue_scripts', function() {
    if ( is_front_page() ) {
        wp_enqueue_style(
            'home-' . wp_get_theme()->get( 'TextDomain' ),
            get_stylesheet_directory_uri() . '/assets/home.css',
            array(),
            filemtime( get_stylesheet_directory() . '/assets/home.css' )
        );
    }
});
```

The handle name should differ per portal (see fingerprint vars: CSS handle naming).

### WP_Query patterns

Vary the query construction across portals. Different patterns produce different SQL signatures (minor, but real).

Pattern 1, named query var:
```php
$featured = new WP_Query( array(
    'posts_per_page' => 5,
    'meta_key' => 'featured',
    'meta_value' => '1',
) );
```

Pattern 2, fluent builder:
```php
$args = array();
$args['posts_per_page'] = 5;
$args['category_name'] = 'destaque';
$featured = new WP_Query( $args );
```

Pattern 3, get_posts (returns array, not WP_Query object):
```php
$featured = get_posts( array(
    'numberposts' => 5,
    'category_name' => 'destaque',
) );
```

Use different patterns for different portals.

### Always reset post data

After every secondary loop:

```php
wp_reset_postdata();
```

Forgetting this breaks pagination and category context.
